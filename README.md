# hyd-abgleich
This project calculates the hydraulic balancing for the heating system in houses. It is based on a Django project.## Project Structure
- `/docs`: Project documentation, including architectural decisions, setup guides, and usage instructions.
- `/src`: Source code for the Django project.
  - `/src/hyd_abgleich`: Main Django project configuration.
  - `/src/heating_system`: Django app for managing heating system components and calculations.
  - `/src/users`: Django app for user authentication and management.
- `/tests`: Unit and integration tests for the project.
- `/data`: Sample data, input files, or database fixtures.
- `/scripts`: Utility scripts for development, deployment, or data processing.
- Python dependencies with the uv tool.
- `Dockerfile`: For containerized deployment.
- `docker-compose.yml`: For local development with Docker.
